Prepare a clearer website.

Edit a working copy, check your changes, then export a proposed catalogue. This page cannot change the live website.

Drafts stay in this browser tab until you export them. Use separate GitHub staff accounts and a reviewed pull request to publish changes. Repository access and MFA must be configured in GitHub.

Publish after review

  1. Export the proposed catalogue and keep a copy on your computer.
  2. In the GitHub repository, open the public folder and choose Add file → Upload files.
  3. Upload the exported catalogue.json. Choose a new branch and open a pull request.
  4. A different staff member reviews the change before merging. Cloudflare redeploys the merged source once its Git connection is configured.
